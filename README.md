# Iron

**Accountability that makes it harder to struggle alone.**

Iron is a simple accountability app built around Proverbs 27:17:

> “As iron sharpens iron, so one person sharpens another.”

Choose someone you trust, enable protection, and keep them informed when it matters.

### Core features

* Accountability partners
* Content blocking
* Alerts for blocked content
* Alerts when protection is disabled or changed
* Weekly accountability summaries
* Ask for support
* Simple activity history

Iron is built to be **simple, affordable, and accountability-first**.

> **Iron sharpens iron.**
